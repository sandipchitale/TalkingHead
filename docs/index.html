Talking Head

A macOS menu bar app and th command that reads text aloud with Apple's built-in voices while an animated face lip-syncs to it. On this page, every feature explains itself.

🔊 Say hello Download Source on GitHub

1Lip sync and blinking

The mouth follows the audio you actually hear, using twelve cartoon mouth shapes that blend smoothly from sound to sound. The eyes blink every few seconds.

🔊 Explain (Daniel)

2Speech bubble

Click the head to show a speech bubble beside it. The word being spoken is highlighted, and the bubble scrolls to keep it in view.

🔊 Explain (Samantha)

3Menu bar applet

Talking Head lives in the menu bar: show the face, type text, play or pause, stop, pick a voice and speed, and launch at login.

🔊 Explain (Daniel)

4Face window toolbar

Below the head: play or pause (Space), type text to speak, pick a file to speak, and pin the window on top.

🔊 Explain (Samantha)

5The th command line

Speak anything from Terminal or scripts.

th Build finished
th -v female -f notes.txt
make && echo done | th
🔊 Explain (Daniel)

6Speak from other apps

Select text in Mail, Safari or almost any app, then choose Services → Speak with Talking Head. For an email, press ⌘A in the message first.

🔊 Explain (Samantha)

7talkinghead:// links

Any web page, note or Shortcut can make Talking Head speak with a link. That's how the 🔊 buttons on this page work.

talkinghead://speak?text=Hello%20there&voice=female
🔊 Explain (Daniel)

8Text fragments

Safari can copy a link to any sentence you highlight on a web page. Send that link to Talking Head and it reads only that passage, not the whole page.

🔊 Explain (Samantha) 📖 Read this card

9Always on top

Pin the face so it floats above your other windows, from its toolbar, from the menu, or with th --always-on-top.

🔊 Explain (Daniel)

Add talking explanations to your own pages

Each 🔊 button is an ordinary link. Put the percent-encoded text in text= and choose a voice:

<a href="talkinghead://speak?text=Hello%20there&amp;voice=female">🔊 Explain</a>

To have Talking Head read a passage that's already on a page, link to the page with a text fragment instead: talkinghead://speak?url= followed by the encoded page address ending in #:~:text=first%20words,last%20words.

The 🔊 links need Talking Head installed on a Mac. The first time you click one, your browser asks whether to open Talking Head; allow it. The 📖 Read this card link needs this page to be opened from its published address.
